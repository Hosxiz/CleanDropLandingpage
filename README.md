จุดประสงค์หลักของโปรเจกต์แบ่งออกเป็น 2 มิติ ดังนี้:

1. มิติด้านธุรกิจและการตลาด (Business & Conversion Goals)
สร้างความเชื่อมั่นในคุณภาพน้ำ (Educate & Build Trust):
มี Interactive 5-Stage Journey จำลองการกรองน้ำ 5 ขั้นตอน พร้อมมาตรวัดความบริสุทธิ์ (TDS Meter) ให้ลูกค้าเห็นภาพว่าน้ำสะอาดขึ้นอย่างไร
มีตารางเปรียบเทียบคุณภาพน้ำ (น้ำประปา vs เครื่องกรองทั่วไป vs เครื่องกรองรุ่นนี้)
แสดงความคุ้มค่าอย่างจับต้องได้ (Cost & Eco Calculator):
มีเครื่องคำนวณเงินออมต่อปีที่ประหยัดได้จากการไม่ต้องซื้อน้ำดื่มบรรจุขวด พร้อมคำนวณจำนวนขวดพลาสติกที่ลดได้ (Eco Impact)
เก็บรายชื่อลูกค้าเป้าหมาย (Lead Generation):
มีปุ่ม Call-to-Action และ Modal Popup สำหรับลงทะเบียน "นัดหมายตรวจเช็กคุณภาพน้ำประปาฟรีถึงบ้าน" เพื่อส่งต่อให้ฝ่ายขายปิดการขาย


2. มิติด้านเทคนิคและสถาปัตยกรรม (Technical Architecture)
Zero Dependency & Fast Loading: ไม่พึ่งพา Framework ขนาดใหญ่ (React/Vue) หน้าเว็บโหลดไว แสดงผลได้ทันที
Component-Based Modular Structure: แยกโค้ดหน้า HTML เป็นส่วนย่อยใน 

src/sections/
 (เช่น hero.html, specs.html, calculator.html) โดยมี 

build.js
 คอยรวมไฟล์อัตโนมัติ ทำให้บำรุงรักษาง่าย
Modern Aesthetic Design: ดีไซน์สไตล์คลีนพรีเมียม โทนฟ้า-ขาว (Pure Clean Aqua & White) สี่เหลี่ยมเรขาคณิตทันสมัย พร้อม CSS Mockup จำลองตัวเครื่องแบบ Interactive ในตัว
